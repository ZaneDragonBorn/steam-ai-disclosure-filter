# README screenshots

Place the images you want published here. Suggested filenames:

- `feature-overview.png` — a collage of actual plugin screenshots, directly below the AI disclosure.
- `search-filter.png` — search sidebar and filtered results.
- `category-filter.png` — category sidebar.
- `wishlist-filter.png` — Wishlist options and AI metadata.
- `game-disclosure.png` — the disclosure on a game's store page.
- `plugin-settings.png` — defaults, exemptions and custom filters.
- `custom-filters.png` — custom filter configuration and exemptions.

In the root README, an image can be inserted with:

```markdown
![Search filtering](docs/images/search-filter.png)
```

Only add images you want public. Crop account names, balances, friend activity and
other personal details when appropriate. These are suggested names, not required files.

The root README uses these seven PNG assets with standard Markdown image links
for compatibility with previews that do not render HTML image elements.

These are AI-assisted presentation images prepared from the maintainer's real
screenshots using the built-in image tool. They are not unedited captures or
pixel-exact verification evidence. The feature overview uses a simple dark layout
and small labels; the other images focus on the relevant controls. Account
headers, avatars and unrelated Steam chrome are omitted.

Keep UI claims consistent with the running plugin when replacing these images.
